# Shared prompts

Starting instructions for NotebookLM, split by output type. Paste them into chat or custom Studio instructions, then **edit** until the report, video, podcast, flashcards, or quiz is actually useful. Save a better version in `collections/<topic>/prompts/` so the next run is not from memory.

| Purpose | Prompt |
| --- | --- |
| Written report / briefing | [report/prompt.md](report/prompt.md) |
| Video overview (single-narrator explainer) | [video/prompt.md](video/prompt.md) |
| Audio podcast / Audio Overview | [audio-podcast/prompt.md](audio-podcast/prompt.md) |
| Flashcards | [flashcards/prompt.md](flashcards/prompt.md) |
| Quiz | [quiz/prompt.md](quiz/prompt.md) |

Use a collection `prompts/` folder only when you need different instructions for that topic. See each purpose folder’s README for filenames after export.
