# Report prompt

Use only the sources in this notebook. Do not invent books, data, quotes, or page numbers.

Write a structured briefing:

1. One-paragraph executive summary.
2. Key claims, each with the source title (and author if known).
3. Agreements and disagreements across sources.
4. Practical takeaways (what a reader might do differently).
5. Open questions and limits of the sources.
6. Short quote list only when a quote is necessary; keep each quote brief and attributed.

Style: clear headings, short paragraphs, bullet lists where they help. No filler. No “as an AI” framing.

If a point is not in the sources, omit it or label it as an inference and say why.
