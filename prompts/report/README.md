# Report prompts

Paste [`prompt.md`](prompt.md) into NotebookLM, then export.

## Expected files

Put exports in `collections/<topic>/outputs/reports/`:

- `<slug>.md` — required
- `<slug>.pdf` — optional (this is the only PDF path that is not gitignored)

Do not paste full chapters into the report. Cite sources by title and author. The export should include a numbered rules / action-plan list as the sources state it, not a second invented playbook. If that list is longer than 5–7 items, it should be split into source-named modules of 5–7 items each, without dropping or merging rules.
