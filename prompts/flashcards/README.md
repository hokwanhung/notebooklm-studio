# Flashcard prompts

Paste [`prompt.md`](prompt.md) when generating or refining a study set.

## Expected files

Put exports in `collections/<topic>/outputs/flashcards/`:

- `<slug>.md` — cards as `##` headings (front) and body (back)
- `<slug>.csv` — columns `front,back,source`
- optional Anki import `.txt` (tab-separated)

NotebookLM may only offer a share link; copy or export via Docs/CSV and save the files here.
