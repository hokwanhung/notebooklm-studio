# Flashcard prompt

Use only the sources in this notebook.

Create a study deck of 20–40 cards:

- One fact, definition, or comparison per card.
- Front: a question or prompt, not a yes/no unless the concept is binary.
- Back: the answer in 1–4 sentences, plus the source title.
- Mix: definitions, “compare X vs Y,” and “what would this author warn against.”
- No trick questions. No cards that require the full book in memory.
- Skip anything not grounded in the sources.

If you can export a table, use columns: front, back, source.
