# Quiz prompt

Use only the sources in this notebook.

Write a 10–15 question quiz:

- Mostly multiple choice (A–D), plus 2 short-answer questions if useful.
- Each question tests one idea: a named rule, a core claim, or a distinction the sources care about — not trivia dates unless the sources stress them.
- Wrong options should be plausible (common mix-ups), not jokes.
- After the correct answer, give a 1–2 sentence explanation and the source title.
- Mark difficulty: easy / medium / hard.
- Do not ask for personal financial advice or “what should I buy.”

If you can export a table, use columns: question, a, b, c, d, correct, explanation, source.
