# Outputs

Drop NotebookLM exports in this folder. Do not add a subfolder per type unless the files pile up.

Slug: `YYYY-MM-DD-short-title`.

| Artifact | Files |
| --- | --- |
| Report | `<slug>.md` (required), optional `<slug>.pdf` |
| Video | `<slug>.mp4` (Git LFS) and `<slug>.md` notes |
| Audio | `<slug>.mp3` preferred (Git LFS); convert WAV first |
| Flashcards | `<slug>.md` plus `<slug>.csv` or Anki `.txt` |
| Quiz | `<slug>.md` plus `<slug>.csv` |
