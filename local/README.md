# Local copies (not git)

Put ebooks here so this machine’s agent can open them. Git ignores everything in `local/` except this file.

```text
local/<collection>/<category>/your-file.epub
```

Finance categories: `1-mindset-and-value`, `2-selection-and-financials`, `3-technical-toolkit`, `4-psychology-and-systems`. List: [`collections/finance-and-investing/README.md`](../collections/finance-and-investing/README.md).

- Copies you are allowed to use only.
- Keep the public list in `collections/<topic>/sources/catalog.md`.
- Prefer EPUB or a DRM-free PDF. Locked Kindle files (AZW/KFX) often cannot be read here.
- Do not put books under `collections/` or `outputs/`.
