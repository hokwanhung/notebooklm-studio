# Report prompt (short briefing) — draft, not the default

Do not use this for a book you want to *implement*. The shared pack [`prompts/report/prompt.md`](../../../prompts/report/prompt.md) is the briefing: short summary plus a full numbered rules list.

Paste this only when you want a skim note with no complete checklist. Not wired into the workflow.

Use only the sources in this notebook. Do not invent books, data, quotes, or page numbers.

Write a briefing of at most 500 words:

1. Executive summary: three sentences.
2. Key findings: at most five bullets. Each bullet names the source title (and author if known).
3. Risks or caveats the sources themselves raise. Do not add market predictions.
4. What the authors claim a reader might do differently. Attribute those claims. This is not personal financial advice: no tickers, products, or allocations.
5. Open questions and what the sources do not cover.

Include a quote only if a short attributed line is needed to avoid misstating a claim.

Style: plain language, short bullets, no filler, no “as an AI” framing. Do not forecast prices, returns, or “what happens next.”

If a point is not in the sources, omit it or label it as an inference and say why.
