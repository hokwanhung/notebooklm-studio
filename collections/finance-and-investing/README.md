# Finance and investing

This collection is the **sole reading list** for these books. Categories below match four NotebookLM notebooks and folders under `local/finance-and-investing/`.

Books stay off git. Bibliographic rows: [`sources/catalog.md`](sources/catalog.md). Notebook URLs: [`notebook.md`](notebook.md). Prompt: [`/prompts/report.md`](../../prompts/report.md).

Do not dump a whole category into one report. Select the sources that share the same question.

## Categories

| Notebook | Folder | What it is for |
| --- | --- | --- |
| 1. Mindset and value | `local/finance-and-investing/1-mindset-and-value/` | Money habits, then value investing |
| 2. Selection and financials | `local/finance-and-investing/2-selection-and-financials/` | Statements, stock picking, then funds |
| 3. Technical toolkit | `local/finance-and-investing/3-technical-toolkit/` | Charts and indicators |
| 4. Psychology and systems | `local/finance-and-investing/4-psychology-and-systems/` | Trading practice; Chan last and separate |

## How to read

**Investor path** (stop after 14 if you do not trade): category 1 → statements and Qiu in 2 → Lynch only if you pick stocks → the two fund books. Dalio is optional.

**Trader path:** same money/value base → category 3 → Douglas, Elder, Turtle, Covel. Chan only if you will code and backtest.

## Reading list

Order inside each category is the read order. Aliases are for prompts.

### 1. Mindset and value

1. [Schaefer] *A Dog Called Money* / 小狗钱钱 — Bodo Schäfer
2. [RichDad] *Rich Dad Poor Dad* / 富爸爸穷爸爸 — Robert Kiyosaki (optional)
3. [Graham] *The Intelligent Investor* / 聪明的投资者 — Benjamin Graham
4. [Marks] *The Most Important Thing* / 投资最重要的事 — Howard Marks
5. [Buffett] *The Essays of Warren Buffett* / 巴菲特致股东的信 — Warren Buffett (Cunningham ed.)
6. [Munger] *Poor Charlie's Almanack* / 穷查理宝典 — Charlie Munger
7. [Dalio] *Principles: Life and Work* / 原则 — Ray Dalio (work system; last or skip)

### 2. Selection and financials

8. [TangChao] *手把手教你读财报* — 唐朝

10. [QiuGuolu] *投资中最简单的事* — 邱国鹭
11. [Lynch1] *One Up on Wall Street* / 彼得·林奇的成功投资 — Peter Lynch
12. [Lynch2] *Beating the Street* / 战胜华尔街 — Peter Lynch

14. [IndexGuide] *指数基金投资指南* — 银行螺丝钉 (own report; you can stop here)
