# Finance and investing

First collection in this studio: finance and investment **books** as NotebookLM sources.

This folder holds the catalog, prompts, and generated artifacts. It does **not** hold the books. Add titles you actually use to [`sources/catalog.md`](sources/catalog.md); do not invent a library.

Create the NotebookLM notebook, upload copies you are allowed to use, then paste the URL into [`notebook.md`](notebook.md).

Default prompts: [`/prompts`](../../prompts/). Finance-specific overrides go in [`prompts/`](prompts/).
